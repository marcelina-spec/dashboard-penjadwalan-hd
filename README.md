# Dashboard Penjadwalan Hemodialisis

## Praktikum Pertemuan 7

### Penggunaan Teknologi dalam Manajemen Kesehatan Ginjal

## Deskripsi

Prototype dashboard penjadwalan hemodialisis (HD) digunakan untuk membantu pemantauan jadwal pasien, sesi pelayanan, mesin HD, dan status pelayanan.

Dashboard menggunakan data sintetis sehingga tidak menampilkan identitas pasien nyata.

## Data

Jumlah pasien: 14 pasien sintetis.

Kode pasien:
P001 sampai P014.

Jumlah mesin:
8 mesin HD.

Sesi pelayanan:
1. Sesi Pagi
2. Sesi Siang

## Fitur Dashboard

1. Ringkasan jumlah pasien.
2. Status pasien selesai.
3. Status pasien berlangsung.
4. Status pasien menunggu.
5. Status pasien terlambat.
6. Status pasien batal.
7. Tabel jadwal hemodialisis.
8. Filter berdasarkan sesi.
9. Filter berdasarkan status.
10. Filter berdasarkan mesin.
11. Status mesin HD.
12. Peringatan mesin maintenance.
13. Peringatan pasien terlambat.

## Manfaat

Dashboard membantu petugas melihat jadwal pasien, mesin, sesi pelayanan, dan status pelayanan secara cepat sehingga koordinasi pelayanan menjadi lebih mudah.

## Risiko

Risiko penggunaan dashboard meliputi kesalahan jadwal, salah pasien, jadwal ganda, mesin maintenance tidak terlihat, downtime, dan tambahan beban input.

## Mitigasi

Mitigasi dilakukan melalui validasi jadwal, indikator status, peringatan otomatis, pemeriksaan ulang, dan penggunaan data sintetis.

## Teknologi

- HTML
- CSS
- JavaScript
- GitHub

## Catatan

Dashboard merupakan prototype dan tidak menggunakan database pelayanan produksi.
